# 🚀 QualAI - Quick Start Guide

## ⚡ One-Command Startup

**For Windows users:**
```bash
# Double-click this file:
start-qualai.bat
```

**For everyone else:**
```bash
npm start
```

## 🎯 What Just Happened?

Your QualAI project is now **fully executable** with these features:

### ✨ **Smart Scripts**
- `npm start` - Starts everything (backend, frontend, landing page)
- `npm run dev:docker` - Runs with Docker containers
- `npm run status` - Monitors all services
- `npm run help` - Shows all available commands

### 🌐 **Access Points**
- **Landing Page**: http://localhost:3000
- **React App**: http://localhost:5173
- **FastAPI Backend**: http://localhost:8000
- **Qdrant Database**: http://localhost:6333 (Docker)

### 🛠️ **Available Commands**

| Command | Description |
|---------|-------------|
| `npm start` | Start all services |
| `npm run dev:docker` | Start with Docker |
| `npm run status` | Check service status |
| `npm run help` | Show all commands |
| `npm run clean` | Clean dependencies |
| `npm run reset` | Complete reset |

## 🚀 **Ready to Run!**
